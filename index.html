외솔 AI 평가 튜터

평가 기준과 결과를 입력하면 맞춤형 평어와 개별 피드백을 자동 생성합니다.

안전한 배포를 위해 본인의 API 키를 입력해야 작동합니다. 입력된 키는 외부로 유출되지 않으며, 브라우저에만 임시 저장됩니다.

👉 1분 만에 무료 API 키 발급받기

튜터 사용 방법

  1. API 키 준비 (필수): 웹사이트 외부 공유 시 보안 위험(개인 키 도용) 및 트래픽 요금 폭탄을 방지하기 위해 각자의 무료 API 키 입력이 반드시 필요합니다.
  2. 과목 설정: 학년, 과목을 선택하고 영역을 적으세요. (영역별로 데이터 자동 저장)
  3. 평가 기준안: 파일(한글, 워드 등)을 한 번 업로드하세요.
  4. 학생 평가 결과: 를 클릭하여 작성 후 업로드하세요. (개인정보 보호를 위해 이름 대신 학번만 사용, 양식 내 단원/성취기준 입력 필수)
  5. 관찰 평가: 아래 관찰 평가 창을 열어 직접 작성합니다. (선택 사항)
※ 내황초 평가 기준안 및 가상 학생 데이터가 전 과목 테스트용으로 기본 적용되어 있습니다.
